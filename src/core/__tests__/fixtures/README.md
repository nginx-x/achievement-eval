# 공개 가능한 합성 정오표

두 PDF는 실제 개인정보를 사용하지 않고 생성한 6문항·10명·2페이지 자료다.
`marksheet-decimal-dots.pdf`는 맞힌 답을 점으로 표시하고,
`marksheet-decimal-numbers.pdf`는 맞힌 답도 선택지 번호로 표시한다.
문항·정답·응답·점수는 표시 방식 외에는 동일하다.

- 배점: 10.4, 10, 10, 10, 19.6, 40점(합계 100점).
- 소수점 총점: 89.60, 79.60, 69.60, 59.60점.
- 경계값·대조군: 90, 80, 70, 60, 100, 0점.
- 페이지 1과 2의 학생 행 높이를 같게 배치해 페이지 간 섞임을 검출한다.
- `generate_marksheet_samples.py`로 재생성할 수 있다(reportlab·맑은 고딕 필요).

기존 `example_data` 없이도 `pdf-synthetic.test.ts`만으로 실행 가능하다.
